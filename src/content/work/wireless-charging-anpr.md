## Overview

Designed a dual-part smart transportation system: an dynamic wireless electric vehicle charging concept powered by electromagnetic induction, paired with a computer vision pipeline for vehicle detection and plate recognition.

## Key Features

1. **Electromagnetic Induction Charging Model:** Modeled charging coil alignment and power transfer dynamics in 3D using SketchUp.
2. **Autonomous Vehicle Alignment:** Implemented object detection with YOLO and TensorFlow to guide vehicles over induction charging pads.
3. **Automatic Number Plate Recognition (ANPR):** Built a real-time OpenCV image pipeline to crop, binarize, and run OCR on vehicle license plates for automated billing.
