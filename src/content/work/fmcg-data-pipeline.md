## The Problem

A global FMCG enterprise needed reliable analytics for product portfolio management. Existing data workflows suffered from fragile manual refreshes, delayed reporting, and legacy CI/CD infrastructure on Azure DevOps that lacked automated quality gates.

## Solution Architecture

1. **Automated Ingestion Pipelines:** Designed PySpark data processing workflows on Databricks to handle high-volume product telemetry and sales data.
2. **Data Transformation & Modeling:** Structured SQL-based transformations inside Azure Data Factory to deliver clean, application-ready schema models for downstream business reporting.
3. **Automated KPI Dashboarding:** Built automated Power BI dashboards with scheduled refresh loops to deliver real-time product performance insights to executives.
4. **CI/CD Infrastructure Migration:** Migrated the codebase and deployment automation from Azure DevOps to GitHub Actions, introducing Infrastructure-as-Code and strict quality checks.

## Key Accomplishments

* **Enhanced Reliability:** Automated pipeline refreshes eliminated reporting delays and improved business decision confidence.
* **Streamlined Engineering:** Unified CI/CD practices on GitHub Actions strengthened deployment consistency and automated security scanning across environments.
