## A deliberately small scope

I built an automatic coding workflow that picks up trivial, refined user stories
and raises a pull request. The starting point matters: a defined task is very
different from an ambiguous product problem.

## Where the workflow ends

The output is a pull request, not a claim that human judgment is no longer needed.
The purpose is to leave developers more time for useful, impactful work.

## What this page demonstrates

The diagram is a conceptual outline of the workflow. It is not a live connection
to a team's work tracker. Implementation details, deployment maturity, and
measured time savings are not published here.
